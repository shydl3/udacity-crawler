为什么我所有随机点都在一条直线上？

这通常说明你生成 xvals、yvals、zvals 时，有两个维度其实没有真正“独立随机变化”。最常见的是：

  • 你把三个坐标都用了同一个数组
  • 某一维被写成了常数
  • samples 组装时列/行方向弄错了
  • 画图时只取到了同一列数据

你前面正确的组装应该是：

python
samples = np.column_stack((xvals, yvals, zvals))

所以现在最该检查的是这 4 个东西，直接打印：

python
print(xvals[:5])
print(yvals[:5])
print(zvals[:5])
print(samples[:5])
print(samples.shape)

如果随机点在一条直线上，通常你会看到像这种情况之一：

  • xvals、yvals 完全一样
  • zvals 全都一样
  • samples 变成了 (3, N) 而不是 (N, 3)
  • 你画图时用了错的列，比如把 samples[:,0] 和 samples[:,0] 画在两个轴上

Summarize this page

  • Moment arm: torque depends on the perpendicular distance to the axis, not arm length alone
  • Rotated frame: when body axes aren’t aligned with rotor arms, that distance becomes smaller than (L)
  • Key relation: for the x-axis example, (d_{\text{perp},x} = L\cos\theta), so (M_x = F L\cos\theta)
  • Quadrotor convention: body axes sit 45° between arms, giving (M_x = \frac{FL}{\sqrt{2}})
  • Why (\sqrt{2}) appears: it comes from converting arm length to the effective perpendicular distance

This page matters because it connects rotor thrust geometry to roll/pitch torque calculations.

dperp代表着什么？为什么不等于臂长

d_perp 表示的是：从旋转轴到力的作用线的垂直距离，也叫力臂。

它不一定等于臂长 L，因为 torque 看的不是“桨离中心有多远”，而是“它离这条旋转轴的垂直距离有多远”。如果机体坐标轴和桨臂完全对齐，那这个垂直距离才会刚好等于 L；但如果坐标轴转了一个角度，真正起作用的只是 L 在垂直方向上的那一部分，所以会变成 L cos(theta)，自然就比 L 小。

你可以把它想成：长度 L 是斜边，d_perp 是投影出来的直角边。
